Introduction

NEXA AI Agent is a lightweight, Python-based voice assistant designed to make system automation completely hands-free. Operating on a continuous active listening engine, it triggers instantly upon hearing the wake-word "Speak NEXA". It features a Standard Command Book for handling core OS tasks—like taking screenshots and web routing—alongside a highly flexible Customize Book that lets users map their own vocal shortcuts without modifying the core logic.

Commands

  • Open Google: "open google" (Triggers Windows key & searches Google)
  • Open Chrome: "open chrome" (Launches Chrome via GUI automation)
  • Open Facebook: "open facebook" (Opens URL directly in webbrowser)
  • VS Code: "vs code" (Opens Visual Studio Code)
  • YouTube Automation: "open youtube" (Asks if you want to search content inside YouTube)
  • Play Music: "play [song name]" (Fetches links from music_library)
  • System Notepad: "notepad" (Launches local text editor)
  • AI Chatbot Mode: "chatbot" (Starts terminal loop for direct Q&A with Pollinations AI)
  • Live Weather Tracker: "weather" or "mausam" (Asks for city name & speaks real-time temperature data)
  • Check Time: "time" (Speaks current local date and time)
  • Camera Security: "face detector" (Privacy guard response block)
  • Nexa AI Engine: Any other words (Forwards command directly to Aiprocess LLM)
  • System Exit: "stop", "exit", or "quit" (Triggers shutdown sequence for Nexa agent)
